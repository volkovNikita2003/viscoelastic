# Распространение волн в двух вязкоупругих полупространствах

## Постановка задачи

Рассматривается двумерная область размером 6000 × 6000 м, состоящая из двум материалов
с границей по оси `z = 3000` м. Такая область моделирует два полупространства.
Все границы поглощающие. Вертикальный точечный силовой источник расположен в точке
`(3000, 2000)` м, то есть на глубине 1000 м. Частота импульса Рикера равна
18 Гц, длительность расчёта — 1.2 с. Время расчета и размеры области подобраны так, 
что отраженные от границ волны не успевают дойти до приемников. 

При этом влияние граничных условий все же может быть, т.к. за один шаг по времени 
информация передается на два узла (т.к. используется схема Русанова с пятиточечным 
шаблоном), за все время расчета скорее всего информация успевает дойти до границ и 
вернуться к источникам. Но эта ситуация не учитывается ни тут, ни в примере 
с полупространством.

Десять приёмников находятся на расстоянии 500 м от границы раздела двух сред 
(`z = 2500` м и `z = 3500` м) в точках с координатами 
`x = 2000, 2500, 3000, 3500, 4000` м. Сохраняются горизонтальная
и вертикальная компоненты скорости.

Одна и та же постановка решается программами RECT и SPECFEM2D. Аналитическое
и отдельное упругое решения в этом тесте не используются.

## Что реализовано

- `rect_sol/` генерирует вязкоупругие проекты RECT с различным `nx`;
- `specfem_sol/` генерирует вязкоупругие проекты SPECFEM2D с различным числом
  спектральных элементов `nx`;
- для обоих решателей создаются копии проектов без сохранения полей и трасс
  для измерения времени;
- `analyze_results.py` строит графики скоростей для всех сеток и сравнивает
  наиболее подробные решения RECT и SPECFEM2D;
- эталоном для обоих методов служит решение SPECFEM2D с наибольшим `nx`;
  ошибки, наклоны и времена сохраняются в CSV;
- вертикальная скорость обозначается как `vy` (`BXZ` в файлах SPECFEM2D).

Результаты анализа записываются в `results/`.

## Требования

Необходимы Bash, Python 3, NumPy, Matplotlib, собранная программа RECT и
собранные `xmeshfem2D` и `xspecfem2D`.

RECT запускается через `rect_sol/bin/rect`. Например, из корня репозитория
ссылку на локальную сборку можно создать так:

```bash
mkdir -p viscoelastic/two_halfspace/rect_sol/bin
ln -s ../../../../rect_git/rect/build/rect \
  viscoelastic/two_halfspace/rect_sol/bin/rect
```

Аналогично, в `specfem_sol/bin/` должны находиться исполняемые файлы или ссылки
`xmeshfem2D` и `xspecfem2D`.

## Запуск

Полный запуск с предварительной очисткой:

```bash
cd viscoelastic/two_halfspace
./run_all.sh
```

Отдельные расчёты и повторный анализ:

```bash
./rect_sol/run_all.sh
./specfem_sol/run_all.sh
python3 analyze_results.py
```

Полная очистка автоматически созданных проектов и результатов:

```bash
./clean_all.sh
```

Наборы сеток, геометрия, длительность расчёта, источник и приёмники задаются в
`rect_sol/generate_projects.py` и `specfem_sol/generate_projects.py`. При их
изменении параметры двух генераторов должны оставаться согласованными.

При этом код генерации проектов для rect и specfem написан на скорую руку под 
конкретную геометрию. При изменении геометрии нужно быть внимательным и 
перепроверять все создаваемые расчетные кейсы. Также желательно переписать код.
