# Тест Komatitsch 1999

## Постановка задачи

Проект воспроизводит двумерную задачу распространения волн от точечного
силового источника в однородной вязкоупругой среде и сравнивает два численных
метода с квазианалитическим решением. Тест основан на примере с сильным
затуханием 7.4 из статьи D. Komatitsch и J. Tromp
[«Introduction to the spectral element method for three-dimensional seismic wave propagation»](https://doi.org/10.1046/j.1365-246x.1999.00967.x),
*Geophysical Journal International*, 139(3), 806–822, 1999.

Расчётная область — квадрат размером 4000 × 4000 м. Источник расположен в
центре области. Восемь приёмников находятся на расстоянии 500 м от источника
по координатным осям и диагоналям. Для каждой станции сравниваются две
компоненты перемещения. Рассматриваются вязкоупругая и упругая модели среды.

## Что реализовано

- `analytical_sol/` — квазианалитические упругое и вязкоупругое решения на
  Fortran;
- `rect_sol/` — генерация и запуск серий расчётов RECT с различным числом
  элементов `nx` (т.е. `nx+1` узлов) по каждому направлению;
- `specfem_sol/` — генерация и запуск серий расчётов SPECFEM2D с различным
  числом спектральных элементов `nx` по каждому направлению;
- для RECT и SPECFEM2D автоматически создаются отдельные проекты без вывода
  результатов, предназначенные для измерения времени расчёта. При измерении 
  времени работы программы запускаются в однопоточном режиме на центральном 
  процессоре;
- `analyze_results.py` сравнивает численные решения с квазианалитическими,
  интерполирует их на общую временную сетку и строит графики решений,
  разностей, сходимости, времени работы и зависимости ошибки от времени;
- ошибки, коэффициенты наклона кривых сходимости и времена расчётов
  сохраняются в CSV-таблицы.

Графики и таблицы записываются в каталог `results/`. Результаты отдельных
численных запусков остаются внутри автоматически созданных каталогов в
`rect_sol/` и `specfem_sol/`.

## Требования

Для запуска необходимы:

- Bash и стандартная утилита `time`;
- Python 3 с пакетами NumPy и Matplotlib;
- Fortran-компилятор `gfortran` либо другой компилятор, указанный в переменной
  окружения `FC`;
- собранная программа RECT;
- собранные `xmeshfem2D` и `xspecfem2D`.

Генератор и скрипты запуска используют локальный путь
`rect_sol/bin/rect`. В этом каталоге должна находиться исполняемая программа
RECT или символическая ссылка на неё. Каталог исключён из Git, поскольку путь
к локальной сборке зависит от рабочей машины. Для сборки RECT из каталога
`rect_git/` данного репозитория ссылка создаётся из корня репозитория командой:

```bash
mkdir -p viscoelastic/komatitsch1999/rect_sol/bin
ln -s ../../../../rect_git/rect/build/rect \
  viscoelastic/komatitsch1999/rect_sol/bin/rect
```

Если RECT собран в другом месте, укажите вместо
`../../../../rect_git/rect/build/rect` абсолютный путь к его исполняемому
файлу. Проверить ссылку можно командой:

```bash
test -x viscoelastic/komatitsch1999/rect_sol/bin/rect
```

Каталог `specfem_sol/bin/` должен содержать исполняемые файлы или корректные
символические ссылки `xmeshfem2D` и `xspecfem2D` аналогично RECT

## Полный запуск

Из корня репозитория выполните:

```bash
cd viscoelastic/komatitsch1999
./run_all.sh
```

Скрипт сначала удалит ранее сгенерированные результаты, затем:

1. соберёт и рассчитает оба квазианалитических решения;
2. сгенерирует и запустит проекты RECT;
3. сгенерирует и запустит проекты SPECFEM2D;
4. проанализирует результаты и сохранит графики и CSV-таблицы в `results/`.

Полный расчёт включает несколько сеток и может занять значительное время.
Текущий тестовый пример занимает примено 4 минуты на процессоре AMD Ryzen 9 7845HX
При ошибке `run_all.sh` выводит название незавершённого этапа.

## Запуск отдельных частей

Каждую часть можно очистить, сгенерировать и запустить независимо:

```bash
./analytical_sol/run_all.sh
./rect_sol/run_all.sh
./specfem_sol/run_all.sh
```

Если все расчётные данные уже существуют, графики можно перестроить отдельно:

```bash
python3 analyze_results.py
```

Полная очистка автоматически созданных проектов, расчётных данных, графиков,
таблиц и Python-кэшей выполняется командой:

```bash
./clean_all.sh
```

## Изменение параметров

Наборы сеток задаются в `NX_VALUES` файлов
`rect_sol/generate_projects.py` и `specfem_sol/generate_projects.py`.
Там же находятся размер области, параметры устойчивости, длительность расчёта,
координаты источника и приёмников. При изменении геометрии номера и координаты
станций должны оставаться согласованными в генераторах RECT и SPECFEM2D, в
Fortran-файлах из `analytical_sol/` и в словаре `STATIONS` файла
`analyze_results.py`.
